# FluidScript Glossary

## Contract
A defined smart contract with state, logic, and execution rules.

## Transaction
A callable operation that mutates state under conditions.

## State
Persistent data held in the contract across blocks and transactions.

## Capability
A declared permission or access boundary.

## Atomic
A deterministic execution block where state changes occur as a single unit.

## Upgrade Policy
Rules used to validate and activate contract versions.

## Reentrancy
A security issue where a contract can be re-entered during execution.

## EVM Compatibility
The ability to use standard Ethereum tooling and behavior.
