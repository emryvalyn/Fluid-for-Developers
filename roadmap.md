# Fluid for Developers Roadmap

## Phase 1: Foundations
- Learn the XOLIX FLUID architecture
- Learn the FluidScript syntax model
- Read the language specification

## Phase 2: Contract Design
- Build a minimal stateful contract
- Learn preflight and atomic semantics
- Understand capability and security rules

## Phase 3: Safety and Upgrades
- Study upgrade policies
- Learn storage compatibility rules
- Review simulation and governance checks

## Phase 4: Production Patterns
- Build native contracts
- Test with the simulator
- Integrate with EVM tools where needed

## Phase 5: Ecosystem Integration
- Connect with wallets and RPC providers
- Use standard Web3 tooling for EVM-compatible deployment
- Publish production-ready contracts
